# Dataset Feasibility Matrix

**Project:** Satellite-Based Multi-Hazard Disaster Risk Prediction and Early Warning System Using AI/ML  
**Document Ownership:** Evaluative feasibility matrix of candidate data sources across all eight hazards.  
**Evidence Standard:** In Phase 0, sources are classified based on authoritative scientific documentation reviewed. Live API testing, account credentials, and sample ingestion are scheduled for Phase 3.

## 2. Decision Summary & Progression Status

* **Feasible for a defined initial task:**
  * `flood` (Sentinel-1 SAR surface water delineation + static susceptibility)
  * `wildfire` (NASA FIRMS active fire danger + Sentinel-2 dNBR burn severity)
* **Feasible with unresolved dependencies:**
  * `landslide` (Copernicus DEM + GPM IMERG rainfall; pending local inventory licensing)
  * `drought` (MODIS VCI + SPEI; pending localized irrigation mask and resolution aggregation)
* **Research required:**
  * `cyclone` (IBTrACS + ERA5; pending integration of NWP atmospheric steering flow)
  * `severe_storm` (Doppler radar / geostationary; pending open real-time radar feed access)
  * `volcanic_activity` (Sentinel-5P $\text{SO}_2$ + SWIR; anomaly detection feasible, eruption forecast deferred)
* **Deferred pending evidence:**
  * `avalanche` (Lacks accessible operational snowpack stratigraphy and localized ground-truth event labels)
